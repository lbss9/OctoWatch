# Changelog

Todas as mudanças notáveis deste projeto são documentadas neste arquivo.

## 0.1.0 — 2026-08-26

- Núcleo Rust com cliente GitHub (Actions, PRs, branches, commits) via UniFFI.
- Login GitHub por OAuth Device Flow e listagem dos repositórios do usuário.
- App Windows (WinUI 3): flyout com vidro Acrylic, bandeja, NavigationView.
- Home com filtro Tudo / Actions / PRs / Branches.
- Configurações: conta, repositórios, eventos, polling, idioma, tema e início com o Windows.
